# 기상 관측 자료 수집 및 그래프

기상청 API에서 관측소 108의 2025년 10월 8일 00시부터 10월 14일 23시까지 시간별 관측자료를 받아 CSV로 저장하고, 기온·습도 그래프를 만듭니다.

## 준비

Python 환경에 다음 패키지가 설치되어 있어야 합니다.

```powershell
python -m pip install pandas requests matplotlib
```

API 인증키는 실행 중 입력합니다. 인증키를 소스 코드나 채팅에 붙여넣거나 공유하지 마세요.

## 실행 순서

PowerShell 또는 VS Code 통합 터미널에서 프로젝트 폴더로 이동한 뒤, 각 명령을 따로 실행합니다. 수집이 끝나 CSV가 생성된 것을 확인하고 그래프 스크립트를 실행하세요.

```powershell
python .\collect_weather.py
```

수집이 성공하면 다음을 실행합니다.

```powershell
python .\plot_weather.py
```

그래프를 먼저 실행하면 CSV가 아직 없을 때 파일을 찾을 수 없다는 오류가 납니다. 수집 실행이 실패한 경우 출력된 오류를 먼저 해결해야 합니다.

## 생성 파일

| 파일 | 설명 |
|---|---|
| `weather_20251008_14.csv` | 관측자료. `datetime`, `temperature_C`, `humidity_pct`, `wind_speed_ms` 열을 UTF-8-SIG로 저장합니다. |
| `weather_response_20251008_14.txt` | API가 반환한 원본 응답 바이트를 그대로 보관합니다. |
| `temperature_20251008_14.png` | 시간별 기온 선 그래프 |
| `humidity_20251008_14.png` | 시간별 습도 선 그래프 |

기존 `weather.csv`는 2025년 10월 1~7일 자료로 보존하며 새 자료로 덮어쓰지 않습니다. 수집이 끝나면 행 수, 결측·중복·누락 시각 수, 기간의 처음·마지막 시각과 기온 통계를 출력합니다. 기존 자료와 새 자료 모두 기온값이 있으면 두 기간의 평균기온 차이도 한 문장으로 출력합니다.

## 처리 방식

- `#`으로 시작하는 API 설명 행을 건너뛰고, 자료 행은 공백으로 분리합니다.
- API 출력 필드 번호 `TM(1)`, `WS(4)`, `TA(12)`, `HM(14)`를 사용합니다.
- 날짜·숫자 변환 실패 개수를 출력합니다. 변환할 수 없는 시각 행은 제외하고, 숫자 변환 실패는 결측값으로 둡니다.
- 음수 기온은 정상 관측값으로 유지합니다. 풍속·습도의 음수 센티널과 기온의 `-99`, `-999`, `-9999`는 결측값으로 처리합니다.
- CSV는 시간순으로 정렬하고 행 인덱스 없이 저장합니다. 중복 시각은 개수를 보고하며 중복 행은 보존합니다.
- 그래프는 데이터를 시간순으로 처리하고 한 시간 간격의 누락 시각을 보충합니다. 기온·습도가 결측인 시각에서는 선이 끊깁니다.
- 두 스크립트는 파일명에 기간이 포함되어 있습니다. 요청 기간을 바꿀 때는 `collect_weather.py`의 `REQUEST_START`, `REQUEST_END`, 출력 파일명과 `plot_weather.py`의 입력 CSV·그래프 파일명을 함께 변경해야 합니다.
